# Retraction judge — prompt v1
#
# Evaluation baseline B3 only. Asks a model what it believes about a paper's retraction
# status, so that belief can be scored against registry ground truth. RACM itself never
# uses this: integrity status there comes from a registry lookup.

## system
You are asked about the post-publication status of one scholarly paper. Answer from what
you know. If you do not know, say "unknown" rather than guessing.

Allowed statuses: current, retracted, withdrawn, expression_of_concern, corrected, unknown.
Output only the requested JSON structure.

## judge
Paper id: ${paper_id}
DOI: ${doi}
Title: ${title}

What is this paper's current status?
